# Roadmap

Biology Skills should expand only when a domain can be maintained with the same clarity, source quality, and review discipline as existing skills.

## Current

- biology core
- genomics

## Next

- cell biology
- biochemistry

- biological statistics

## Later

- pathology
- cancer biology
- plant biology

## Cross-domain priorities

Prefer shared foundations over duplicated rules. Important cross-domain topics include provenance, experimental units, biological versus technical replication, batch effects, measurement versus prediction, association versus causation, uncertainty, data leakage, benchmark contamination, species transfer, and cell-type or tissue context.
